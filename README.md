## 📖 About

**Shezy Tech Solutions** is a founder‑led tech studio landing page built to showcase who I am, what I build, and how to get in touch. This repo holds the single‑page marketing site — designed and coded from scratch, fully responsive, and framework‑free.

The site covers:

- 👋 An intro to the founder and the studio
- 🛠️ Core skills — full‑stack development & mobile app development
- 🧩 Services offered — website build, app build, custom systems
- ⚙️ Tools & technologies used day to day
- 💼 Selected projects — Smart Hostel Management System, Online Voting System, Fraud Detection System
- 🧭 A simple 4‑step process (Discover → Design → Develop → Deploy)
- 📬 A contact section with a working mail‑to form

## 🖥️ Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, Grid & Flexbox, no framework) |
| Interactivity | Vanilla JavaScript (mobile nav, scroll reveals, dynamic tool chips, mailto form) |
| Fonts | [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts |

No build tools, no dependencies — it's a single static HTML file, so it runs anywhere.

## ▶️ Getting Started

Clone the repo and open the file directly — no install step required.

```bash
git clone https://github.com/<your-username>/shezy-tech-solutions.git
cd shezy-tech-solutions
```

Then just open `index.html` in your browser, or serve it locally:

```bash
# Python
python3 -m http.server 8000

# or Node
npx serve .
```

Visit `http://localhost:8000` in your browser.

## 🌍 Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/ (root)` folder.
4. Save — your site will be live at:
   `https://<your-username>.github.io/shezy-tech-solutions/`

## ✨ Features

- 📱 Fully responsive — mobile, tablet & desktop
- 🎨 Custom design system (colors, type scale, spacing) via CSS variables
- 🌀 Scroll‑reveal animations with `IntersectionObserver`
- 🍔 Accessible mobile navigation menu
- ✉️ Contact form with `mailto:` fallback — no backend required
- ♿ Respects `prefers-reduced-motion` for accessibility
